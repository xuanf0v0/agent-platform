# Desktop File Organizers & Office Supplies Sets — US Title / Item Highlights Reference

Use for US Amazon title-only or title + Item Highlights tasks involving desk file organizers, vertical file organizers, mesh mail holders, paper tray organizers, desk accessory kits, and office supplies sets.

## When user asks only for title optimization

Do not run the full staged listing workflow. Use a compact micro-workflow:

1. Parse current title, product type, brand requirement, core specs, core keyword, and competitor ASINs.
2. Use SellerSprite keyword data and competitor ASIN title structure when available.
3. Output one recommended short title plus 5–8 alternatives.
4. If the user asks for Item Highlights, provide 1 recommended line plus 2–3 alternatives.
5. Keep explanations brief and focused on keyword order, confirmed specs, and why long accessory lists were removed.

## Title strategy

Default to <=75 characters for non-media categories.

Prioritize:

1. Highest-intent core keyword near the front.
2. One key structural differentiator such as `5-Section`, `4 Letter Trays`, `10 Pcs`, or `Mesh`.
3. Confirmed color such as `Black`, `Pink`, or `Purple`.
4. Brand only if the user wants brand exposure or it fits without displacing the core keyword.

Move overflow to Item Highlights / bullets:

- Long room lists: office, school, home, classroom, mailroom.
- Full component lists in office supply kits.
- Secondary keyword variants.
- Full paper/folder object lists.

## Fast title + Item Highlights workflow

When the user supplies a current title, US site, exact core keyword, colour/specs, and competitor ASIN:

1. Inspect the live ASIN title and bullets for structure, but treat competitor attributes as unverified for the user's product.
2. Draft a punctuation-light title of no more than 75 characters, keeping the exact core phrase and the highest-value confirmed specs.
3. Draft one readable searchable Item Highlights line of no more than 125 characters that complements rather than repeats the title.
4. Verify both character counts before delivery.
5. Keep the response compact: recommended title, recommended Item Highlights, character counts, a short rationale, and optional alternatives. If the user asks only for `产品亮点` after a title has already been approved, return one recommended Item Highlights line plus a Chinese reference; do not re-run the full workflow or flood the answer with variants unless requested.

## Repeated US office-organizer title workflow

For this user's rapid title + Item Highlights tasks:

1. Inspect the supplied competitor ASIN live before drafting. Capture its current title and only those structural claims that are visibly supported by the page.
2. Do not transfer a competitor-only drawer, pen holder, handle, adjustable divider, load claim, material treatment, or paper-size compatibility to the user's product unless the user's brief or clearly matching own-product page confirms it.
3. Default final titles to **no punctuation or special symbols**, including no hyphens, commas, parentheses, ampersands, or slashes. Keep the natural product phrase readable rather than turning the title into a comma-separated keyword list.
4. Put the exact user-supplied core phrase near the front; then add the most decision-critical structure (tier count, tray count, compartment count, drawer, handle) and color. Keep the recommended title under 75 characters and verify the count with a tool.
5. When the user asks for `产品亮点` or `商品亮点`, provide one searchable Item Highlights sentence under 125 characters, plus character count and Chinese reference. Use commas for readability in Item Highlights even when the title itself avoids punctuation.
6. Title and Item Highlights must complement each other: title carries core phrase + critical configuration + color; Item Highlights carries material, secondary storage modules, compatible paper/items, and use context.

### Item Highlights compression patterns

Keep one readable sentence, usually 105–124 characters:

- `Material + tier/compartment structure + secondary module + files/items + within-reach benefit`
- `Color/material + tray/file-holder structure + papers/folders/mail/office supplies`

Do not spend Item Highlights characters repeating every word already present in the title. Avoid detailed dimensions unless fit is the primary purchase risk.

### Competitor patent disclosure

If the live competitor page explicitly claims a US design patent, patent application, or application number:

- Record the claim as a competitor-page statement, not as verified legal status.
- Do not copy the competitor's distinctive design wording or imply clearance.
- Add a short human IP-review warning when the user's product appears structurally close.
- Keep patent analysis separate from title optimization; title differences do not remove product-design infringement risk.
