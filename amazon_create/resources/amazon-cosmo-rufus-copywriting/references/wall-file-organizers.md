# Wall File Organizers / Hanging Wall Files (US)

Use this reference when creating Amazon US copy for wall file organizers, hanging wall files, wall-mounted file holders, mail sorters, and office/classroom paper organizers.

## Buyer-intent map

| Intent cluster | Buyer question | Copy response |
|---|---|---|
| Desk decluttering | Will this get paper off my desk? | Lead with vertical wall storage and visible paper sorting |
| Paper classification | Can I separate mail, folders, bills, forms, and documents? | Use 3-tier / multi-pocket language and list common paper types |
| Mounting flexibility | Can I use it on a wall, door, cubicle, or office partition? | State exact confirmed mounting options and thickness range; avoid "fits all" |
| Small essentials | Can it hold keys or badges too? | Highlight bottom hooks for keys, ID badges, lanyards, and small accessories |
| Material confidence | Is it metal or plastic? | Use black metal / iron construction if verified; do not invent powder-coated/rustproof |
| Setup confidence | Does it include hardware? | Mention screws, wall anchors, screwdriver, and instructions when confirmed |
| Trust / load | How much can it hold? | Limit load claims to the tested component and conditions, e.g. rear hooks tested up to 11 lb under proper use |

## Recommended bullet order

1. **3-Tier File Sorting** — wall file organizer, desk clutter, mail/folders/bills/forms/documents.
2. **Flexible Mounting** — wall plus verified door/cubicle/office partition use; include thickness range if provided.
3. **Hooks for Essentials** — bottom hooks for keys, badges, lanyards, small accessories; entryway/front desk/classroom.
4. **Black Metal Frame** — metal construction, black finish, professional home office/classroom/reception look.
5. **Hardware Included** — screws, wall anchors, screwdriver, instructions; tested rear-hook load if substantiated.

## Title strategy under 75-character rule

Prioritize: `Brand + Tier Count + Wall File Organizer + One Critical Attribute`.

Example patterns:

- `JMHUD 3 Tier Wall File Organizer Metal Hanging Holder with Hooks`
- `10 Tier Wall File Organizer for Papers Folders Clipboards and Mail Black`

When the user supplies an exact core phrase such as `10 Tier Wall File Organizer`, preserve it intact and place it at the front. If the user allows the brand to be omitted, use that space for only the most relevant document types or one verified differentiator. Move office/home/classroom/cubicle, magazine-holder, assembly, and other secondary terms into Item Highlights, bullets, or backend fields. Avoid commas and hyphens when the user's upload style calls for symbol-free titles.

### Item Highlights for wall organizers

Use one readable searchable line rather than a keyword string. Complement the title with omitted storage objects, vertical-space benefit, use scenes, or setup disclosure. Only include facts confirmed for the user's product.

Example based on a confirmed 10-tier wall-mounted organizer that requires assembly:

`10 tier wall storage organizes papers folders clipboards magazines and mail to reduce desk clutter assembly required`

Do not import competitor-only metal, coating, dimensions, label panels, hardware, or load claims into the user's Item Highlights.

- black metal finish / metal construction

- commercial grade

## Magnetic file-holder subtype

Use this subtype guidance for magnetic file holders designed for refrigerators, steel file cabinets, lockers, or magnetic whiteboards.

### Buyer intent and naming

Prioritize these distinctions before writing:

- Primary category term: `magnetic file holder` or `magnetic file organizer`; do not default to generic `wall file organizer` when magnet mounting is the main purchase reason.
- Confirm tier count, pocket opening, Letter-size compatibility, overall dimensions, magnet count/coverage/thickness, and whether screw hardware is also included.
- Separate **magnetic no-drill use on verified ferromagnetic surfaces** from optional screw mounting. Do not imply magnets work on every refrigerator, stainless-steel appliance, wall, glass board, or non-magnetic surface.
- Useful scenes: steel filing cabinet, magnetic whiteboard, locker, and compatible refrigerator; office, classroom, home command center, and mail sorting.

### Claim discipline

- Load capacity must include the tested surface, load distribution, magnet configuration, and test method. A competitor's `holds up to 11 lb` claim is not evidence for the user's product.
- Magnet thickness alone does not prove holding strength; avoid converting `3 mm magnet` into `heavy duty` without testing.
- Use `powder-coated`, `rust resistant`, or `oxidation resistant` only when supplied or substantiated. Never upgrade these to `rustproof`.
- If dimensions appear in different orders across Amazon modules, normalize them to labeled `W x D x H` only after confirming orientation from reliable product data or images. Flag unresolved dimension-order conflicts instead of silently choosing one.

### Competitor-ASIN intake protocol

When the user supplies only a US competitor ASIN:

1. Inspect the live Amazon detail page before asking the user to repeat data that is publicly available.
2. Set a US delivery ZIP when needed so the visible offer is in USD; record price as a time-sensitive snapshot, not a permanent fact.
3. Capture brand, title, current price, rating count, variants, overview attributes, bullets, category path, and stated mounting/load claims.
4. Use the product page's rating histogram, Amazon review summary, and topic counts as directional VOC signals when available.
5. Do **not** invent low-star complaints when review bodies are hidden behind account verification. State that raw low-star VOC remains unverified and do not finalize differentiation until review text or another reliable VOC source is available.
6. Return a concise competitor baseline and then request the user's own product specs before advancing through audience, product interpretation, differentiation, and final-copy approval gates.
