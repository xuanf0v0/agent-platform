# Listing Creation Constitution

1. Source order: Seller Central validators > Amazon announcements > law/evidence > policy skill > user brief > third-party MCP > creation SOP > competitor/hypothesis.
2. Non-media Title ≤75 characters; Item Highlights ≤125; Search Terms ≤250 UTF-8 bytes.
3. Never invent dimensions, materials, certifications, compatibility, warranties, or percentages.
4. Staged approval is default; skip only when the user explicitly asks.
5. MCP/third-party data is market context only, not product fact authorization.
6. Sensitive categories require human compliance review labels.
