# Amazon Image Design Notes for COSMO/Rufus Listing Workflow

Use this reference after listing copy is confirmed and the user wants image design, image optimization, or image analysis.

## Authority and evidence boundary

- Amazon marketplace/category image rules and the local evidence hierarchy override every creative suggestion in this reference.
- Use only user-confirmed product facts. Competitor images, market research, and style references may inspire presentation, but cannot authorize materials, dimensions, included components, certifications, performance, safety, sales, or review claims.
- Do not carry China-platform advertising rules into an Amazon deliverable. Apply the target marketplace's current Amazon policy and applicable law instead.
- Missing proof stays visibly marked as `待补`; do not turn a visual concept into an unsupported product claim.

## Default post-copy handoff

After final copy is confirmed, ask whether the user wants image design. If yes, do not default to asking for uploads. Prefer ASIN-driven research first:

1. Ask for product ASIN and competitor ASINs if not already known.
2. Investigate product image groups through Amazon page, SellerSprite, browser image extraction, and vision tools.
3. Request uploaded images only if ASIN tools cannot retrieve the image group, or if the user has private/unpublished product photos/design drafts.

## Image design workflow

1. Confirm task type: image design, image optimization, or image analysis.
2. Reuse approved copywriting outputs: audience, purchase motives, buyer concerns, 5 selling points, keyword/intent library, and confirmed-fact ledger.
3. Classify the main conversion driver: visual appeal, pain-point relief, rational/specification proof, or emotional/lifestyle value. Explain the choice without inventing conversion data.
4. Lock a **Campaign Style Lock**: at most three colors, product scale, lighting, typography, texture treatment, and prohibited drift such as invented logos, random backgrounds, or inconsistent rendering styles.
5. Build a verified benefit table before storyboarding: `Feature -> Advantage -> Buyer Benefit -> Evidence`. Unsupported evidence is `待补`, not copy.
6. Analyze existing product/competitor image groups by image order when images are actually available. Describe what each image communicates and ask whether the user approves the interpretation.
7. Deliver a storyboard only, then pause for confirmation before producing final image copy or generation prompts.
8. After confirmation, design 8 images: 1 main image + 7 secondary images. Each must specify visual task, selling point, color palette, product angle, background, layout, detail treatment, image copy, and generation prompt.

## Storyboard approval gate

The storyboard assigns one distinct decision job to each image. Do not repeat the same feature across the set merely with a different background.

| Image | Default decision job |
|---|---|
| Main | Identify the exact included product clearly and compliantly |
| Secondary 1 | Primary verified benefit or purchase reason |
| Secondary 2 | Critical specification, construction, or mechanism |
| Secondary 3 | Differentiating detail with evidence |
| Secondary 4 | Concrete use scenario and intended user/object |
| Secondary 5 | Setup, compatibility, care, or limitation that prevents returns |
| Secondary 6 | Package contents, size comparison, or verified choice guidance |
| Secondary 7 | Trust/risk reducer, FAQ, or multi-use summary without unsupported promises |

For each row provide the visual task, first visual focal point, composition, prohibited expressions, and fact/evidence dependency. Ask for approval before generating final image copy.

## Amazon image rules

Main image:

- Pure white background.
- Actual product photo/render; no illustration, hand-drawing, or cartoon style.
- No added text, icons, watermark, or non-included props.
- Product should occupy about 85% of the frame.
- Show the whole product clearly, not just a detail crop or multi-angle collage.
- Parent and child variations need their own main images.
- Longest side should be at least 1000 px; shortest side should not be below 500 px. Use high-resolution JPEG when possible.

Secondary images:

- May show details, specifications, function, usage scenarios, installation/use steps, comparisons, and lifestyle scenes.
- Should support product understanding and conversion, not overload the buyer.
- Main and secondary image dimensions should be consistent when possible.

## Image selling-point principles

- Prefer one image, one selling point for major differentiators.
- If combining selling points, use hierarchy: one dominant selling point and secondary supporting details.
- Avoid information overload: no more than 2 important selling points and no more than 3 common/supporting selling points in one image.
- Choose from three expression modes:
  - Objective display: full product, close-up details, specs, structure.
  - Objective + scenario: product in relevant use scene with explanatory labels.
  - Emotional/lifestyle rendering: post-use feeling, atmosphere, quality-of-life improvement.
- Product detail images should focus on product introduction and feature highlighting.
- A+ images should explain the selling point and remove doubts.
- Posts and ad custom images can use more lifestyle/emotional composition.

## Scoring dimensions

Run five independent reviews. A strong score in one dimension cannot compensate for a failure in another:

1. **Compliance and evidence**: Amazon image rules, confirmed facts, disclaimers, and claim authorization.
2. **Benefit translation**: every important feature is translated into a buyer-relevant benefit and supported by evidence.
3. **Visual focal point**: product scale, one dominant message, readable hierarchy, and restrained copy.
4. **Material and medium expression**: lighting, texture, background, and rendering style match the real product and stay consistent with the Campaign Style Lock.
5. **Narrative continuity**: the eight images have distinct jobs and progress from identification through proof, use, objection handling, and decision support.

If any dimension is below the agreed quality threshold, revise only the affected dimension and re-check compliance afterward.

## Hardware Cloth image pattern

For US hardware cloth products, a strong 8-image set usually is:

1. Main image: white background, 3D roll view, round roll opening visible, mesh partly unfolded, product about 85% of frame, no text.
2. Specs image: roll size, mesh opening, wire gauge, material, with close-up mesh detail.
3. Gauge/strength image: close-up of wire and welded joints; emphasize 19 gauge or true verified gauge without absolute claims.
4. Mesh barrier image: 1/2 inch mesh and small pest/barrier use; use safe wording like “helps block”.
5. Chicken coop/poultry run scene: show installed hardware cloth on coop frame.
6. Garden/raised bed scene: show plant/vegetable/flower protection.
7. Cut and install image: wire cutters, staples/U-nails/zip ties, gloves and eye protection.
8. Multi-use image: chicken coop, garden fence, raised beds, rabbit hutch, tree guard, crawl-space vents.

Avoid risky image copy:

- “Predator Proof” → use “Helps Protect Your Coop Space”.
- “100% Pest Proof” → use “Helps Block Small Pests”.
- “Rust Proof” → use “Helps Resist Rust”.
- “Indestructible” → use “Heavy-Duty” or “Built for Outdoor Projects”.
- “Best Chicken Wire” → use a factual product/spec phrase.
