# Greenhouse Polycarbonate Panels — US Listing Notes

Use for US listings for polycarbonate sheet / greenhouse panels / greenhouse replacement panels.

## Buyer intent
- Replace damaged greenhouse roof or wall panels.
- Build or repair cold frames, raised bed covers, small greenhouses, canopies, carports, patio covers, pool roofs, or curved outdoor frames.
- Keep plants in a steadier growing environment while allowing sunlight through.
- Get panels that are easier to cut/trim than rigid glass and stronger than thin plastic film.

## Bullet order
1. Size/options + roof/wall/cold frame/garden DIY use.
2. Twin-wall insulation / hollow structure / heat-loss reduction.
3. Clear sunlight transmission + UV-protected aging/yellowing resistance.
4. Weather-ready / impact-resistant panel vs thin plastic film covers.
5. Cut-to-fit DIY use + scenario expansion + safe cutting/install note.

## Safe claims
Use:
- helps reduce heat loss
- heat retention / helps retain warmth
- allows sunlight to pass through / 90% light transmission (only if provided by user/source)
- UV-protected material helps resist yellowing / brittleness / outdoor aging
- UV-blocking coating helps filter harsh rays (use `blocks up to 99% UV rays` only when the user confirms data support)
- impact-resistant polycarbonate panels help handle rain, wind, temperature swings, and outdoor exposure
- weather-resistant outdoor coverage
- stronger option than thin plastic film covers
- trim to fit / cut to size / cut-to-fit
- bendable panels / bending flexibility when provided

Avoid unless backed by test data:
- unbreakable
- shatterproof
- hail proof
- hurricane proof
- 100% UV proof
- never yellow
- waterproof forever
- windproof support / waterproof protection as standalone claims
- indestructible

US wording note: prefer `pool cover panels` over `pool roofs`; prefer `weather-resistant coverage` over literal `windproof / waterproof` unless the user has proof.
