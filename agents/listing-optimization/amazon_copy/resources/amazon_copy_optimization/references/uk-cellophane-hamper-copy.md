# UK Cellophane / Hamper Packaging Copy Notes

Use for Amazon UK listings involving cellophane bags, hamper bags, clear gift bags, sweet/cookie bags, pull bows, twist ties, and OPP/polypropylene gift packaging.

## Workflow pattern from repeated ASIN audits

When the user asks in Chinese for `给出 <ASIN> 的标题、五点、search term 的优化建议`, treat it as an audit + optimization-direction request, not automatic final copywriting. Provide:

1. Current baseline from SellerSprite ASIN detail: title, price, rating/review if available, variations, bullet availability.
2. ASIN traffic signals from SIF/SellerSprite. If ASIN-level traffic is empty, state that and pivot to market keywords for the product class.
3. Keyword table from SellerSprite/SIF with UK monthly search volume, purchase rate or history where available.
4. Title diagnosis: what to keep, what to weaken/remove, and a recommended title structure.
5. Five-bullet strategy by purchase decision stage.
6. Search Term buckets and avoid-list.
7. SOP score + final approval question before producing final English title/bullets/Search Term.

## UK localization choices

- Prefer `sweets` over US-style `candies`.
- `Party favours` is UK-appropriate.
- For hamper products, prefer natural phrasing like `Cellophane Bags for Hampers`, `Hamper Wrap Bags`, `Hamper Wrapping Cellophane`, or `Cellophane Wrap for Hampers` over awkward phrases like `Hamper Basket Wrap Bags`.
- Use `biscuits` as an additional UK term where relevant; keep `cookies` only when keyword data supports it.

## Compliance and expectation-control pitfalls

- Do not use `food safe` unless the user provides food-contact certification or the listing already has verified support. If present in current title, flag as a P0 compliance risk and recommend removing/weakening.
- Avoid unsupported absolute claims: `airtight`, `waterproof`, `tear proof`, `rip proof`, `keeps food fresh`, `FDA approved`, `guaranteed strong`.
- Safer phrases: `suitable for dry treats`, `ideal for wrapped sweets`, `designed for gift presentation`, `helps keep gifts neatly presented`.
- For hamper bags, always align size expectations: distinguish small/medium hamper bags from extra-large hamper wrap bags and advise buyers to measure baskets before purchase. This reduces mis-clicks and returns.

## Positioning heuristics

- If pack count is high but size is moderate (e.g. 50 pack, 35 x 50 cm), position as bulk small-to-medium gift/hamper/party/craft packaging, not oversized hamper wrapping.
- If pack count is low but size is very large (e.g. 3 pack, 125 x 100 cm), position as extra-large hamper / oversized gift basket wrapping and justify value with size, 3 MIL thickness, pull bows, and twist ties.
- If small self-adhesive bags (e.g. 8 x 13 cm), position around clear cellophane bags, sweet bags, cookie/biscuit bags, jewellery/card/craft bags, and party favours.

## Competitor benchmark cues

Common competitor structures in this product class:
- `Extra Large Cellophane Bags for Hampers + size + bow`
- `Large Cellophane Bags with Pull Bows + size + clear/polypropylene`
- `Self Seal Clear Cellophane Bags + pack count + size + cookies/sweets/cards`

Use competitor structures for diagnosis only. Do not copy competitor copy.
